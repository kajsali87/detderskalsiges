# CLAUDE.md

Se [`AGENTS.md`](AGENTS.md) for fuld projektkontekst og arbejdsregler. Kort:

- Kajsa Li Paludans hjemmeside "Det der skal siges" (dansk). Live: https://kajsali87.github.io/detderskalsiges/
- Hele siden er **én selvstændig `index.html`** — billeder og skrifter embeddes som `data:`-URI'er.
- **Ingen em-dashes (—); brug dansk tankestreg (–).**
- Bevar det rolige, redaktionelle udtryk (Oswald-titel + Palatino, bone/oxblood). Løs teksttyngde med struktur, ikke ved at forsimple.
- Deploy: rediger `index.html` → `git add -A && git commit && git push` (GitHub Pages, ~1 min).
- Strategi og åbne opgaver: [`ROADMAP.md`](ROADMAP.md). Opsætning: [`README.md`](README.md).
